# نور — موقع مفروشات (الكويت)

- `npm install && npm run build && ADMIN_PASSWORD=كلمة-سر-قوية npm start` ثم افتح `/` للموقع و`/admin` للوحة الطلبات.
- رقم الواتساب: `src/config.js` (`WHATSAPP`).
- الفيديو الذي يتحرك مع السكرول: `public/media/tour.mp4` و`tour-m.mp4`. لاستبداله بتصويرك الخاص ضع المقاطع في `media-src/` ثم `bash scripts/prepare-video.sh`.
- لقطات الفيديو الحالية من Mixkit (ترخيص مجاني): أرقام 47286, 35896, 3110, 4196, 3111, 40211.
- مجسمات الكنب (glb) من Khronos glTF Sample Assets (Wayfair، CC BY 4.0).
- إن لم يوجد فيديو، يعمل مشهد ثلاثي الأبعاد بديل تلقائياً.
