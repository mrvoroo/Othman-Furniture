# نور — فيلا مفروشات ثلاثية الأبعاد (الكويت)

موقع كامل أُعيد بناؤه من الصفر: جولة سينمائية من البوابة والحديقة إلى داخل الفيلا، خريطة من فوق لدورين، دخول أي غرفة، تصاميم متعددة لكل غرفة، وبطاقات تعريف بالخامات. ولوحة أدمن لاستقبال الطلبات.

## التشغيل
```bash
npm install
npm run build
ADMIN_PASSWORD="كلمة-سر-قوية" npm start     # الموقع على / ولوحة الأدمن على /admin
```
- رقم الواتساب: `src/config.js` (`WHATSAPP`).
- الغرف والتصاميم والخامات: `src/data.js`.
- جلب المجسمات والخامات (CC0) من Poly Haven: `python3 scripts/fetch-assets.py` (يحتاج `@gltf-transform/cli`).

## المصادر
- مجسمات وخامات وHDRI: [Poly Haven](https://polyhaven.com) (CC0).
- كنب مخمل وكرسي: Khronos glTF Sample Assets (تصميم Wayfair، CC BY 4.0).
- شاشة الكمبيوتر المضيئة والتلفزيون والسجاد والمرتبة: مجسمات بُنيت في الكود (لا يوجد نموذج حديث مجاني).
